# Telegram Quiz Bot

## Описание проекта

**Telegram Quiz Bot** – это бот для Telegram, реализованный на Laravel. Он позволяет пользователям участвовать в квизах (викторинах), отвечая на вопросы с разными типами ответов (текст, изображения, опросы). Бот обрабатывает пользовательские команды, отслеживает прогресс и хранит данные в базе данных.

## Основные возможности
- Поддержка квизов с разными типами вопросов
- Обработка команд Telegram (`/start`, `/quiz`, `/help` и др.)
- Хранение информации о пользователях и их результатах
- Гибкая система обработки обновлений от Telegram API
- Возможность интеграции с разными базами данных
- Хранит информацию о списках лидеров игроков
- Поддерживает возможность самостоятельно добавлять и редактировать вопросы для викторины с указанием нескольких правильных вариантов ответа  

## Особенности проекта 
- Проект написан без использования бибилотек для работы с Telegram API
- Как уловие , работа реализована без получения хуков от Telegram, для работы задействована Cron для проверки наличия новых поступивших сообзений боту
